# NDX-100 成分股监控器（Gate.io 永续数据源）

只监控 **纳斯达克 100（NDX 100）成分股中、Gate.io 已上架永续合约** 的那部分标的，外加宽基 ETF（QQQ / SPY）。当前名单 **66 只 NDX 成分 + QQQ/SPY = 68 个标的**，覆盖美股**盘前 / 盘中 / 盘后**，按「24h 涨跌幅」和「24h 振幅」超阈值发邮件到你的 QQ 邮箱。

> **为什么范围这么窄？** 交易所上架的股票合约有 447 个（含大量中概股、日韩台股、杠杆 ETF），噪音太大。只盯 NDX 100 成分，信号更干净。
>
> **为什么用 Gate 而不是币安/OKX？** 币安合约 API（`fapi.binance.com`）屏蔽美国 IP（HTTP 451），GitHub Actions 服务器在美国，用不了；OKX 虽可达但股票合约 227 个太多。Gate 公开行情接口在美可达，且合约有 `contract_type=stocks` 字段可精准区分股票。

- **名单固定可控**：`config.json` 的 `stocks` 就是 NDX100 ∩ Gate 股票合约，想加想减直接改这里。
- **无需任何 API key**：Gate 公开行情接口，连注册都省了。
- **一次调用拿全量**：`tickers` 接口一次返回所有合约行情。
- **24 小时运行**：跑在 GitHub 云服务器，你电脑关不关机都行。

## 一、文件结构

| 文件 | 作用 |
|------|------|
| `monitor.py` | 核心脚本（筛名单、取行情、判阈值、发邮件） |
| `config.json` | 阈值、NDX 股票名单、宽基 ETF、收件人 |
| `.github/workflows/monitor.yml` | 定时运行（盘前5分钟/盘后10分钟/盘中15分钟） |
| `state/` | 冷却状态（自动生成，别删） |

## 二、监控规则（默认参数）

| 对象 | 涨跌幅阈值 | 振幅阈值 |
|------|-----------|---------|
| 宽基 ETF（QQQ、SPY） | ±1.3% | ≥5% |
| NDX 个股 | ±3% | ≥5% |

- **涨跌幅** = Gate `change_percentage`（24h 涨跌幅）
- **振幅** = (24h 最高 − 24h 最低) / 24h 前价格，24h 前价格由涨跌幅反推
- **冷却**：同一标的触发后 60 分钟内不重复告警

## 七、常见问题

**Q：需要注册 API key 吗？**
不需要。Gate 公开行情接口无需 key，脚本只用 Python 标准库。

**Q：想加/减监控标的？**
改 `config.json` 的 `stocks` 数组（填 ticker，不含 `_USDT`）。脚本会自动校验 Gate 是否上架，没上架的跳过并提示。

**Q：想改阈值？**
改 `config.json` 的 `thresholds`：`index_change_pct`（宽基ETF）、`stock_change_pct`（个股）、`amplitude_pct`（振幅）。

**Q：Gate 上新了新的 NDX 成分股怎么办？**
把它加进 `config.json` 的 `stocks` 即可（需确认 Gate 已上架该合约）。

**Q：怎么停止？**
删仓库，或 `Actions` 页 `Disable workflow`。
